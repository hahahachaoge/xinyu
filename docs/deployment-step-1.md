# 上线第 1 步：权限与后端计分

文档复核日期：2026-11-14。下文权限与计分说明对应当前代码；文末测试数量是注明日期的历史结果。本阶段的后续 AI 与部署工作已有记录，见 [AI 与知识库验收](deployment-step-2-ai-rag.md) 和 [部署说明](deployment-step-3.md)。

## 权限规则

后端按照控制器方法执行权限检查，未明确开放的接口默认要求管理员。JWT 有效期为 8 小时；每次请求检查账号是否仍存在、当前数据库角色及密码凭据版本。修改或重置密码后旧 Token 失效；不符合当前凭据校验规则的旧 Token 需要重新登录。

| 操作 | 游客 | 普通用户 | 管理员 |
| --- | --- | --- | --- |
| 注册、登录、阅读文章/公告/量表 | 允许 | 允许 | 允许 |
| 提交测评 | 需登录 | 以本人身份提交 | 以本人身份提交 |
| 查询、删除测评与收藏 | 拒绝 | 仅本人 | 可管理全部 |
| 查询、发送、删除聊天及提交反馈 | 拒绝 | 仅本人的会话 | 可管理全部 |
| 创建评论 | 拒绝 | 作者固定为本人 | 作者固定为本人 |
| 修改、删除评论 | 拒绝 | 仅本人 | 可管理全部 |
| 修改个人资料 | 拒绝 | 仅本人，无法修改角色/账号/密码 | 可管理账号 |
| 用户、知识库、量表、评分规则及统计管理 | 拒绝 | 拒绝 | 允许 |
| 直接创建或修改测评结果 | 拒绝 | 拒绝 | 拒绝 |

普通用户的测评、收藏列表即使不传 `userId`，也只查询本人数据。查询他人测评详情不会返回记录。公开页面中的作者资料只返回昵称、头像和 ID，密码和密码哈希不会序列化到响应。

公开注册强制创建普通用户，并忽略传入的账号 ID 与角色。新密码采用 BCrypt；已有 MD5 密码在成功登录后升级，账号与原密码保持可用。新设密码至少 6 个字符，UTF-8 编码最长 72 字节。普通资料修改接口无法修改密码，需使用独立的修改密码接口并验证旧密码。

当前未接入邮件或短信身份验证，在线忘记密码功能已关闭。页面会提示联系管理员核验身份后重置。浏览器生成的图片验证码不能证明手机号或邮箱的所有权。

头像、附件和视频上传会携带登录请求头；管理员导出改为经过认证的文件下载，Token 不放入下载链接。

## 计分接口

`POST /assessmentRecord/submit`，请求头携带登录 Token。选项序号从 **0** 开始：

```json
{
  "scaleInfoId": 1,
  "answers": [
    { "questionId": 1, "optionIndex": 0 },
    { "questionId": 2, "optionIndex": 2 }
  ]
}
```

题目 ID 必须换成该量表的真实题目，并一次提交全部题目。后端读取数据库中的选项分值，计算总分，按包含上下边界的评分区间匹配唯一规则，保存用户、得分、结果解读、答案快照及服务端时间。返回数据包含 `suggestion`，前端直接展示返回结果。

客户端传入的用户 ID、总分、结果标签和完成时间不会用于计分。漏答、重复、跨量表题目、越界选项、无效选项配置、没有匹配规则或匹配多个区间均拒绝保存。旧的 `/assessmentRecord/addOrEdit` 已关闭，避免绕过计分写入结果。

本次不修改数据库表结构，也不重算历史记录。旧数据来源于原先的前端计分，不能作为本次后端校验已覆盖历史数据的证明。数据库中的选项分值应为 JSON 整数；评分区间不能重叠，且应覆盖量表可能产生的全部分数。量表的心理学依据和使用许可仍需单独核实。

## 老师首次拉取后的管理员设置

评审测试现在可使用 [固定演示账号](judging-demo.md)，启用 `demo` 配置后无需下面的手动注册和 SQL 步骤。下文保留普通模式的首次管理员初始化方法。

按 README 配置环境变量、数据库并启动后，先通过注册页面创建自己的账号。没有共享默认管理员密码。

由数据库管理者在 CMD 进入 MySQL（密码在提示后输入）：

```cmd
mysql -u root -p qa_mental_health_knowledge_services_adolescents
```

先确认自己刚注册的账号：

```sql
SELECT id, user_name, role_type FROM sys_user;
```

将下面的 `YOUR_ACCOUNT_ID` 替换为已确认的账号 ID，只为该账号授予管理员权限：

```sql
UPDATE sys_user SET role_type = 1 WHERE id = YOUR_ACCOUNT_ID;
```

退出并重新登录，登录时选择管理员。此步骤仅供首次初始化，后续账号在管理后台维护。不要把数据库管理员密码放入 Git、截图或命令行参数。

## 验证与启动（CMD）

后端目录：

```cmd
cd QaMentalHealthKnowledgeServicesAdolescents.springboot
mvn.cmd test "-Dmaven.repo.local=.maven-repository"
mvn.cmd spring-boot:run "-Dmaven.repo.local=.maven-repository"
```

另开 CMD，前端目录：

```cmd
cd QaMentalHealthKnowledgeServicesAdolescents.elementui
npm.cmd run build
npm.cmd run dev
```

前端开发地址仍为 `http://localhost:8000`，后端为 `http://localhost:7406`。更新需要重启后端并重新登录；正式部署需要同时发布新前端与新后端。

回归测试使用模拟数据库与 MockMvc，覆盖匿名访问、普通用户调用管理接口、当前角色与 Token 角色不一致、账号删除、密码变更、个人资料提权、他人记录访问、伪造计分字段以及非法答案。它们不替代真实数据库和部署环境的联调验收。

2026-11-10 验证结果：后端 40 项测试通过；前端生产构建通过。
