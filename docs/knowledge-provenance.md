## 后续如何标注出处

Markdown 或 UTF-8 TXT 文件末尾使用普通的参考章节：

```markdown
## 参考来源

- [机构名称：文章标题（发布日期）](https://机构官网/原文地址)
```

正文按节标明依据哪条参考资料，另外写清原文、整理稿或自编材料等性质、整理日期及适用范围。系统读取本地文件的该章节，在后台文档详情展示其中的 HTTPS 链接；聊天页不展示出处。不自动认定引用真实，也不会联网替文件补一个看起来相关的网址。PDF、Office 等格式的外部出处目前不会自动提取。

后台已启用“编辑”入口，可保留文档 ID 更新附件；修改附件保存后会请求重新向量化，失败时可手动重试。仅修改标题或描述不会重新生成向量。重新解析会替换分块，旧聊天片段可能失效；仅修复向量关联时使用“重建分块向量”以保留分块 ID。
